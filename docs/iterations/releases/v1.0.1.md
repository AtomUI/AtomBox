## 版本目标

v1.0.0 是 AtomBox 的首个正式版本。本版本唯一功能改动是建立完整的桌面端本地化体系，使 AtomBox 支持简体中文和英文，并允许用户在应用设置中切换后立即生效。

## 非目标

- 不在 v1.0.0 增加简体中文和英文以外的翻译。
- 不翻译文件名、远程路径、Bucket 名称、账号名称、Provider 品牌名和协议标识。
- 不让 UI 语言影响网络协议、签名、JSON 持久化或日志的稳定格式。
- 不在 Core、Application、Providers、Transfer 或 Infrastructure 中引入对 AtomUI、Avalonia 或翻译资源的依赖。
- 不把供应商返回的原始技术错误强制翻译；用户摘要本地化，原始消息保留在错误详情和日志中。

## 验收标准

- 首次启动选择 `system` 时，简体中文系统显示中文，其他系统显示英文。
- `system` 在启动、重新选择或重置设置时解析；运行期间不监听操作系统语言变化。
- 用户可在应用设置中选择“跟随系统”“简体中文”或“English”。
- 在语言下拉框完成选择后当前窗口立即切换，不依赖设置页“保存”按钮，不要求重启，也不丢失当前页面、导航位置、用户输入或其他未保存设置。
- 左侧导航、页面标题、按钮、表头、空状态、状态栏、Message 和后续打开的弹窗使用同一种语言。
- 用户可见错误使用 Desktop 本地化摘要；错误详情继续提供未翻译的底层原始消息、错误码和上下文。
- AtomUI 内置控件与 AtomBox 自有文案同步切换。
- 重启后恢复用户保存的语言；旧版偏好文件自动回退到 `system`。
- 中英文资源键及格式化参数一致，缺失资源具有确定的英文回退。
- 英文长文案在 Windows、macOS 和 Linux 的主要页面中不重叠、不截断关键操作。
- 完整构建和自动化测试通过，并完成中英文 Desktop smoke test。

## 发布前检查

- 扫描 Desktop 中面向用户的硬编码中文和英文，确认已迁移或列入明确豁免。
- 检查所有资源键的中英文覆盖、占位符和单复数处理。
- 检查系统语言、固定中文、固定英文和无效历史配置四种启动场景。
- 检查运行时连续切换语言，不重复订阅事件、不泄漏 ViewModel 或重建当前业务状态。
- 检查协议格式继续使用 `InvariantCulture`。
